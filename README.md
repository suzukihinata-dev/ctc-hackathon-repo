## 開発の進め方

このリポジトリはプルリクエストベースで開発を進めます。

1. `master` から作業ブランチを切る（例: `feature/xxx`、`fix/xxx`）
2. 作業をコミットしてブランチを push する
3. `master` に対してプルリクエストを作成する
4. レビュー・チェックを通過したらマージする

### 自動マージ（@release）

`.github/workflows/auto-merge.yml` により、コミットメッセージに `@release` が含まれるプルリクエストは自動でマージされます。

- 即時マージ可能な場合はその場でマージ
- ブランチ保護などで即時マージ不可の場合は auto-merge を有効化し、必須チェック通過後に自動マージ
