# 落胆予報 — UIモック

学期途中の成績を可視化するアプリの**見た目だけ**のモックです。バックエンドなし、単一HTMLで動きます。

## 開き方

デプロイ済み: **https://ochikomi-yohow.vercel.app**

ローカルで開く:

```bash
open mock/index.html
```

または任意の静的サーバーで:

```bash
python3 -m http.server 8000
# http://localhost:8000/mock/index.html
```

## 画面フロー

1. **開始画面** — スプレッドシート接続カードと「成績の収集を開始」ボタン
2. **収集処理画面** — 5ステップの収集アニメーション(赤ペンの✓)+ 進捗バー + 実行ログ
3. **結果ダッシュボード** — 落胆予報ゲージ / 予測サマリー / 落胆の要因 / 採点基準と成績 / 小テスト推移グラフ。授業タブで3科目を切替可能

URLハッシュで直接画面を開けます(デモ共有用):

- `mock/index.html#screen=progress` … 処理画面
- `mock/index.html#screen=result` … 結果画面

## 注意

- 成績・確率はすべてダミーデータです
- デザインは CVD(色覚多様性)検証済みパレットを使用(採点項目のカテゴリ色)
